# 法拉第 AI 教師

以麥可·法拉第（Michael Faraday, 1791–1867）為角色的高中物理 AI 教師網頁。

- 人物資料：肖像、生平年表（1805–1860）、以他命名的單位與定律
- 與「法拉第老師」對話，兩種模式：**探究引導**（先預測、觀察再解釋）與**聽他說故事**
- 單一檔案 `index.html`，直接用瀏覽器開啟即可；可搭配 GitHub Pages 發布

> 在 GitHub Pages 或本機開啟時沒有連上 AI，只能回答頁面上的 5 個預設問題；自由提問需在 claude.ai 的 Artifact 版本中使用。

肖像：Thomas Phillips《Michael Faraday》(1842)，National Portrait Gallery, London，經 Wikimedia Commons，公有領域。
